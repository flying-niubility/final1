# 智慧校园公共服务信息中心（Campus Hub）

围绕"校园公共服务与学习生活"主题开发的响应式信息与数据展示中心，覆盖**食堂美食、自习室、讲座活动**三大场景。纯前端实现，无需后端服务器。

---

## 一、功能与作业要求对照

| 作业要求 | 实现情况 |
| --- | --- |
| 信息首页 + 至少 2 个功能页面，响应式适配手机和桌面 | 首页 `index.html` + 食堂 `canteen.html` + 自习室 `studyroom.html` + 讲座 `lecture.html`，基于 Bootstrap 栅格与媒体查询适配手机/平板/桌面 |
| 交互查询或管理模块（筛选、搜索、添加、修改任选） | **全部实现**：菜品搜索/筛选/排序/添加；自习室搜索/筛选/预约/取消预约；讲座搜索/筛选/报名/取消报名 |
| 基于 JSON 的数据加载 | 4 个本地 JSON 文件位于 `data/` 目录，通过 jQuery `$.ajax` 异步加载 |
| 至少两类有效图表（ECharts / Chart.js） | 使用 ECharts，共 **4 类**：折线图（食堂客流趋势）、饼图/环形图（场所使用率、口味分布）、柱状图（菜品数量、楼栋占用率、讲座报名率）、仪表盘（座位综合使用率） |
| 与主题相关的三维展示区域（Three.js / A-Frame） | 首页"三维校园导览"使用 Three.js：图书馆、食堂、报告厅、体育馆、宿舍楼，支持拖拽旋转、滚轮缩放，**点击建筑跳转对应页面** |
| 完整的错误提示和运行说明 | JSON 加载失败/超时、无降级数据、表单校验、无搜索结果、WebGL 不支持、CDN 加载失败均有提示；运行说明见下文 |

技术约束：只使用课堂技术（HTML + CSS + JavaScript），使用了 **jQuery 3.7** 与 **Bootstrap 5.3**，使用了 **Three.js 0.160**，未使用 React/Vue，无后端。

## 四、运行说明（重要）

由于浏览器安全策略，**直接双击用 `file://` 打开时无法通过异步请求读取本地 JSON 文件**。请使用以下任一方式启动一个本地服务器（推荐第 1 种）：

### 方式 1：VS Code Live Server（推荐）

1. 用 VS Code 打开本项目文件夹 `final1`；
2. 在扩展商店安装 **Live Server**；
3. 右键 `index.html` → **Open with Live Server**；
4. 浏览器自动打开 `http://127.0.0.1:5500/index.html`。

### 方式 2：Python 内置服务器

电脑装有 Python 3 时，在项目根目录（`final1`）打开终端执行：

```bash
python -m http.server 8000
```

然后浏览器访问：<http://localhost:8000/index.html>

### 方式 3：Node.js 环境

```bash
npx serve .
```

按终端提示的地址访问即可。

> 兼容说明：如果直接双击 `index.html`（file://），页面会检测到 JSON 加载失败，**自动改用内置示例数据**正常演示全部交互，并在顶部显示黄色警告条提示使用本地服务器运行。

**网络要求**：Bootstrap、jQuery、ECharts、Three.js 均通过 CDN 引入，首次运行需联网。

## 五、页面功能说明

### 1. 首页 `index.html`

- 英雄区 + 4 项校园核心数据（数字滚动动画）；
- **三维校园导览**：鼠标/触摸拖拽旋转、滚轮/双指缩放；悬停建筑高亮并显示名称，点击图书馆/食堂/报告厅跳转对应页面；
- 图表：今日各食堂客流趋势（折线图）、校园场所使用率（环形饼图）；
- 快捷服务入口与校园公告。

### 2. 食堂美食 `canteen.html`

- 关键字搜索菜名；按食堂、口味筛选；按价格/评分排序；
- 点击"添加菜品"，在弹窗中填写信息（带表单校验），新菜品即时出现在列表（带"用户添加"标识）并更新图表；
- 图表：各食堂菜品数量（柱状图）、口味类型分布（饼图）。

### 3. 自习室 `studyroom.html`

- 搜索房间名/楼栋；按楼栋、状态（空闲/紧张/满员）筛选；
- 卡片展示实时座位进度条与开放时间；
- 点击"预约座位"，填写姓名、学号、时段（含学号格式校验、重复预约校验、满员校验）；
- "我的预约"可查看全部预约并取消；
- 图表：各楼栋座位占用率（柱状图）、全校综合使用率（仪表盘）。

### 4. 讲座活动 `lecture.html`

- 按标题/主讲人/地点搜索；按分类筛选；
- 卡片展示讲座信息与报名进度，一键报名/取消报名，满员自动锁定；
- 图表：各场讲座报名率（横向柱状图）。

## 六、数据说明

- **基础数据**：全部存放在 `data/` 目录的 4 个 JSON 文件中，可用文本编辑器直接修改，刷新页面即可生效（需通过本地服务器运行）；
- **用户数据**：添加的菜品、自习室预约、讲座报名保存在浏览器 `localStorage`，仅存在当前浏览器中，刷新不丢失；清除浏览器数据后重置。

## 七、错误提示设计

| 场景 | 提示方式 |
| --- | --- |
| JSON 文件加载失败 / 请求超时 | 顶部黄色警告横幅，说明原因并建议使用本地服务器；自动降级到内置示例数据 |
| 无降级数据可用 | 顶部红色错误横幅；列表区显示错误占位卡片 |
| 表单输入不合法 | Bootstrap 内联红框提示 + 右上角 Toast 补充说明 |
| 重复预约 / 重复报名 | 红色 Toast 拦截 |
| 搜索无结果 | 列表区显示空状态插图与引导文案 |
| 浏览器不支持 WebGL | 三维区域显示错误说明，建议更换浏览器 |
| Three.js CDN 加载失败 | 9 秒看门狗检测后在三维区域提示检查网络 |
| localStorage 不可用或已满 | Toast 提示写入失败 |

## 八、常见问题（FAQ）

1. **打开页面后图表和列表不显示真实数据？**
   多半是用 `file://` 直接打开所致。请按"四、运行说明"启动本地服务器。

2. **页面样式错乱、三维场景空白？**
   请检查网络连接（CDN 资源需联网），建议使用 Chrome / Edge 最新版。

3. **想恢复初始数据？**
   清除浏览器站点数据（localStorage）即可；JSON 数据本身不会被页面修改。

4. **需要在手机上演示？**
   启动本地服务器后，手机与电脑连同一 Wi-Fi，用电脑局域网 IP 替换 `localhost` 访问即可（如 `http://192.168.1.10:8000`）。
